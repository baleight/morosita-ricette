# Ricette Morosità Runner

Contenuto da pubblicare in un repo GitHub. Non modificare `index.json` a mano: rigenerarlo con
`node estensione-morosita/tools/publish.mjs` (calcola hash e firma). Vedi `estensione-morosita/README.md`.

- `recipes/*.json`: una ricetta per comma (selettori `fields`, passi `steps`, esiti `outcomes`).
- `index.json`: elenco versioni, SHA-256 e firma.
